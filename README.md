# Datheon Python Internship

## Task 2: Stock Portfolio Performance Tracker

A Python-based stock portfolio tracker developed as part of the Datheon Python Internship.

### Features
- Enter stock ticker symbols
- Record stock purchase prices
- Enter the number of shares
- Enter current stock prices
- Calculate total investment
- Calculate current market value
- Calculate profit or loss
- Calculate percentage returns
- Export portfolio summary to CSV
- Input validation and error handling

### Technologies Used
- Python 3
- CSV Module

### How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run the following command:

python portfolio.py

5. Enter the stock details.
6. Type `done` to finish entering stocks.
7. View the portfolio summary in the terminal and CSV file.
